# 环洋账单整理工具使用说明

## 快速启动

双击 `启动环洋工具.bat` 或 `HuanyangTool\HuanyangTool.exe`

## 使用流程

1. **点击【开始处理账单】**
2. 依次选择4个文件：
   - ① 账单1（成本汇总）—— 提供主单号→客户单号映射
   - ② 账单2（成本明细）—— 实际加工对象
   - ③ 报价表 —— 环洋报价表 xlsx
   - ④ 打单问题统计表 —— 天图未查到的标记写入这里

3. 工具自动完成：
   - 账单加工（填运单号、翻译、报价、差异）
   - 天图核验（批量查询偏远/超长/住宅等标记）
   - 问题登记（未查到的标记写入统计表）
   - 企业微信通知

4. 处理完成后点【打开输出文件夹】查看结果

## 输出文件

- `outputs/` 目录：
  - 环洋_天图核验清单_*.csv —— 天图查询清单
  - 天图核验结果_*.csv —— 天图查询结果
  - 环洋核价报告_*.txt —— 统计报告
- 账单2（成本明细）会被原地修改，原始文件自动备份为 `*_原始备份.xlsx`

## 首次使用配置

### 1. 天图账号（必需）

编辑 `credentials.local.json`：
```json
{
  "tiantu_user": "你的天图账号",
  "tiantu_pass": "你的天图密码"
}
```

### 2. 企业微信通知（可选）

编辑 `notify.local.json`，填写企业微信机器人 webhook 密钥和金山文档参数。不配置时通知会静默跳过，不影响主流程。

## 常见问题

### Q: 启动后什么都没有？
A: 确保以下文件完整：
   - `HuanyangTool/HuanyangTool.exe` —— 启动器
   - `main_flow/main_flow.exe` —— 主流程
   - `check_tiantu/check_tiantu.exe` —— 天图引擎
   - `打单费用名称中英文翻译.xlsx` —— 翻译表
   - `credentials.local.json` —— 天图账号（必填）

### Q: 天图查询失败？
A: 检查：
   1. `credentials.local.json` 里的账号密码是否正确
   2. 网络能否访问天图系统
   3. 查看 `outputs/环洋_天图运行_*.log` 日志

### Q: 翻译列全是空的？
A: 确保 `打单费用名称中英文翻译.xlsx` 存在且格式正确（A列中文、B列英文）

### Q: 处理速度？
A: 天图核验是最慢环节：
   - 批量查询（偏远/超长等）：约 45-60 秒/批（13条/批）
   - 逐单查询（住宅私人/地址更正）：约 20-30 秒/单
   - 100条清单预计 5-15 分钟
