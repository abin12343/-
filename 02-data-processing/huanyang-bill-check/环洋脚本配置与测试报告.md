## 四、通知功能配置指南

### 企业微信通知配置

**步骤**:
1. 企业微信群 → 群设置 → 群机器人
2. 添加机器人 → 获取 Webhook 地址
3. 复制 key 参数（地址中 `key=` 后面的部分）
4. 填入 `notify.local.json` 的 `wecom_key` 字段

**示例**:
```
Webhook: https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=abc123-xyz
取 key: abc123-xyz
```

### 金山文档配置

**步骤**:
1. 创建金山文档运行记录表
2. 表格 → 工具 → AirScript
3. 创建脚本获取 file_id、script_id
4. 获取 API Token
5. 填入 `notify.local.json` 的 `kdocs` 字段

**表格示例**:
| 应用名称 | 运行时间 | 运行时长 | 账号标识 | 运行状态 |
|---------|---------|---------|---------|---------|
| 环洋打单 | 2026-09-18 15:57 | 45.2秒 | 脚本 | 成功 |
