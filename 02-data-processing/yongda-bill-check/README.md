# 永达 UPS 账单核价检查（第一阶段）

用途：从打单系统(永达)获取原始客户账单（`TTTX_UPS*.xlsx`），自动完成费用名称中英翻译、
按报价表核价（商业/住宅基础运费、固定附加费、分区阶梯费、百磅计费）、计算差异，
输出《核价结果.xlsx》与《报告.txt》；结束后弹窗选择 xlsx，把问题汇总追加到空白行，
为人工复核和后续对接天图核验打基础。

依赖：Python 3 + openpyxl（无需 pandas/Excel 打开）。
网页获取还需要 playwright（只装库即可，浏览器复用本机 Edge）：

```bash
pip install -r requirements.txt
```

自动登录凭证：在项目目录放一份 `credentials.local.json`（已加入 .gitignore，不会提交），
内容示例见下；也可继续用环境变量（`YONGDA_USER/YONGDA_PASS`、`TIANTU_USER/TIANTU_PASS`），
环境变量优先级更高。

```json
{
  "yongda_user": "TTTX",
  "yongda_pass": "你的密码",
  "tiantu_user": "天靶",
  "tiantu_pass": "你的密码"
}
```

网页自动化会以**全屏**方式打开浏览器，确保“应收”等右侧列正常加载。

完整流程：

0. `python main_flow.py` —— **主流程：一条命令跑完全程**
   **弹出窗口选择要处理的账单 xlsx（不再自动下载压缩包；自动校验表头，选错会提示并重新弹出）**
   → 核价（四列加工副本 + 天图核验清单）
   → 天图逐单核验 → 合并问题（核价差异 + 天图缺标记）后弹窗选择统计表写入。
   流程结束自动向金山文档《数据表》写入运行记录，并向企业微信群推送结果
   （网络失败只打印提示，不影响主流程结果）。
   常用参数：
   - `--input <账单xlsx/目录>`：跳过选表弹窗，直接用指定账单；
   - `--skip-engine / --skip-tiantu / --skip-write`：跳过某一步；
   - `--tiantu-limit N`：天图只测前 N 个任务（联调用）；
   - `--dry-run`：最后一步只打印待写问题，不弹窗不写入。

手动分步（等价于主流程）：

1. `python fetch_bill.py`（**可选，主流程已不再调用**）—— 打开本机 Edge 访问打单系统，
   登录后自动点 财务管理 → 客户账单 → 全部 → **只勾选列表第一行账单** → 导出账单；
   下载/解压后的 xlsx 存到 `客户账单导出_auto_*` 目录，源文件不做任何修改。
   （登录环节建议手动完成，脚本检测到“财务管理”后自动继续；也可用环境变量
   `YONGDA_USER`/`YONGDA_PASS` 尝试自动填表。）
2. `python run_yongda_check.py --input <最新导出目录>`（不带参数也会自动定位最新一批导出）
   引擎自动选该批第一份账单，翻译 → 核价 → 汇总；同时生成：
   - 《*_加工副本_*.xlsx》：原始数据逐行保留，仅插入并填充 翻译/第一次收取费用/报价表/差异 四列
     （翻译、报价、差异已填；第一次收取费用留待天图核验后回填）；
   - 《*_天图核验清单_*.csv》：按费用类别去重生成的待天图核验单号清单。
3. `python check_tiantu.py` —— 打开天图系统逐单核验（偏远/超偏远/住宅私人/超长/超重/address），
   输出《天图核验结果_*.csv》；缺标记的单号作为问题参与汇总。
4. `python write_problems_to_stats.py` —— 弹出文件选择窗口：选《打单问题统计表》等 xlsx
   （自动校验目标表和是否被 Excel 占用，不符合会提示并重新弹出），
   自动合并“核价问题 + 天图缺标记问题”，写入**首个空白行**，
   按表头自动对应 运单号/费用名称/金额USD/备注 四列（备注列填写核价差异
   或天图核验缺标记原因，如“核价差异 R-P=-1.02（账单P=3.27，SOP报价R=2.25）”、
   “天图核验：运单号列未见红色“偏远”标记”），
   重复的 (单号, 费用名称) 默认跳过（备注自动合并；若原行备注为空则补写备注）。

运行方式：

```bash
python fetch_bill.py
python run_yongda_check.py --input D:/项目/永达对账单/客户账单导出_auto_20260903_153000
python check_tiantu.py --limit 5     # 先小批量实测
python run_yongda_check.py --no-write-dialog        # 调试：跑完不弹窗
python run_yongda_check.py --write-target <汇总文件> # 调试：指定写入目标不弹窗
python run_yongda_check.py --tolerance 0.02          # 临时调整差异容差
```

输入（路径可在 config.json 修改）：
- 账单：`D:/项目/永达对账单/客户账单导出_*/TTTX_UPS*.xlsx`
  （系统原始导出**不含** SOP 提到的 翻译/第一次收取费用/报价表/差异 四列，脚本按表头定位，
  对有无这四列都兼容；同一批多份文件只取第一份）
- 翻译表：`打单费用名称中英文翻译.xlsx`（Sheet1 优先，Sheet2 兜底）
- 报价表：`UPS Ground报价 2026.1.15 .xlsx`（sheet 主报价 + Sheet1 百磅报价）

输出：`outputs/` 下按账单文件名+时间戳生成结果文件；运行日志写入
`D:/MyScripts/logs/yongda-bill-check.log`；四列及百磅 sheet 写回原表前会先备份
（config: `run.enrich_source_in_place`；原表被 Excel 占用时自动生成 `_已核价` 副本）。

## 规则口径与待校准点（重要）

1. 差异列按 SOP 公式 `差异 = 报价R - 费用金额P`；`|差异| > 容差(默认0.01)` 的行进入问题清单。
   超偏远类别单独放宽到 0.05（2.82/2.87 视为与 2.85 一致）。
2. 固定价：偏远 2.25、超偏远 2.85、住宅附加费 3.25、住宅附加费调整 3.25、
   地址更正 25.5——都在 config.json 的 `prices` 中，改价只改配置。
   运费更正(SCC)不按固定价：按 G 列子单号找到运费行后复制其 R 公式，
   且公式中 K（重量）的行号自动改成更正行当前行，H（分区）等其它引用保持运费行不变；
   报告中 R 也按“当前行重量 + 运费行分区”重算，与 Excel 公式结果一致。
3. 超尺寸/超重阶梯价（分区 2→18 等）也在 `prices` 中，按费用类型命中的行才计算。
4. 百磅计费：先按客户单号透视汇总，总重 <500 用 200-499 档、<1000 用 500-999 档、
   >=1000 用 1000+ 档，报价 = 总重 × 费率 / 100；仅使用分区 2-8。
   费率取第 2 套（Sheet1 中 “Rate Per Hundredweight Unit”，与账单分项一致）。
   导出表每行重量被取整，|差异| <= 0.10 视为正常舍入（config: hundredweight_tolerance）。
5. 所有费用只处理分区 2-8，分区不在 2-8 的行标记“zone-out-of-scope”进入待处理清单。
6. 燃油附加费、UPS 折扣及运费更正关联行（地面/燃油/折扣）不核算，列为信息类。
7. “住宅调整”(Residential Adjustment) 经真实账单验证 = 住宅报价 − 商业报价
   （如分区8/30lb：21.67 − 16.70 = 4.97，与账单一致），引擎已按该口径实现。
8. 天图红色标记：偏远/超偏远/超长/超重 需在运单号行内出现**红色**标记元素才算“是”
   （颜色取页面元素 computed color；灰色或其它颜色不算；若页面结构取不到独立标记元素，
   才退回纯文字判断）。住宅私人/住宅附加费调整 按“应收”文字判断：先横向滚动到应收列、
   再滚动收集该单号数据行文本，应收列只要包含 住宅私人/私人住宅/住宅地址费/私人地址
   等字样即算“是”（无需独立显示，夹杂空格/换行也能命中）。address 按“运踪”文字判断。

原始账单的只读副本始终保留在导出压缩包与 `_原始备份.xlsx` 中；重复运行安全，不会重复加列。
